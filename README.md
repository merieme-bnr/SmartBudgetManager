This document provides a quick overview of Smart Budget Manager, its main features, the requirements for using it, and the basic steps to get started with the Excel workbook.

README – Getting Started:
1. Project Overview:
Smart Budget Manager is an Excel workbook designed to help users organize and monitor their personal finances. It allows users to record income and expenses, calculate their financial balance, monitor budget limits, and visualize expenses through a dashboard and a pie chart.
2. Main Features :
	Dashboard: Displays total income, total expenses, the remaining balance, and the overall budget status.
	Transaction Management: Allows users to record the date, description, type, category, income, expenses, and notes for each transaction.
	Category Management: Provides expense categories such as Food, Transport, Rent, Health, and Education, with budget limits.
	Budget Monitoring: Compares expenses with budget limits and displays a warning when the overall budget is exceeded.
	Expense Visualization: Provides a pie chart showing expenses by category.
3. Requirements:
To use Smart Budget Manager, users need a compatible spreadsheet application, preferably Microsoft Excel, and the SmartBudget_Manager.xlsx file. An internet connection is not required for normal offline use.
4. Getting Started :
1)	Open SmartBudget_Manager.xlsx using Microsoft Excel.
2)	Select the Transactions sheet.
3)	Enter each transaction in a new row, including its date, description, type, category, and corresponding income or expense amount.
4)	Open the Categories sheet to review or adjust the available categories and budget limits.
5)	Return to the Dashboard to review the financial summary, budget status, and expense chart.
5. Important Notes:
Enter transactions in the appropriate columns and avoid modifying cells containing formulas. The dashboard summarizes the transactions within the workbook's predefined data range, so users should keep their entries within that range. Review the budget status regularly to monitor spending.
